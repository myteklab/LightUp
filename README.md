# LightUp

A Lite-Brite inspired LED art creator. Place colored pegs on a dark grid and toggle the power to see your creation glow!

## Features

- 8 vibrant LED colors plus eraser
- Click or drag to paint LEDs on the grid
- Toggle power ON/OFF for realistic glow effects
- Multiple grid sizes (20x15, 30x22, 40x30, 50x38)
- Touch support for mobile devices
- Save and load projects

## How to Use

1. Select a color from the palette
2. Click or drag on the grid to place colored LEDs
3. Use the eraser (X) to remove LEDs
4. Toggle power ON to see your creation light up
5. Change grid size for larger or smaller canvases
